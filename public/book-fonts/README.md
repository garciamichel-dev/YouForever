# Book fonts (YouForever)

Static, Latin-subset instances of SIL Open Font License fonts, used by the book viewer and
embedded in the downloaded PDF so both render with identical metrics.

They are **modified versions** (weights pinned from the variable fonts, characters limited to Latin,
optical size pinned at 12 for Source Serif 4), so they carry neutral names: some originals declare
Reserved Font Names (Lora, Playfair Display, Source), which modified versions may not use.

| Original family (Google Fonts) | Name of this modified version |
|---|---|
| Caveat | YFBook CV |
| Cormorant Garamond | YFBook CG |
| EB Garamond | YFBook EBG |
| Libre Baskerville | YFBook LB |
| Lora | YFBook LO |
| Manrope | YFBook MR |
| Playfair Display | YFBook PD |
| Plus Jakarta Sans | YFBook PJS |
| Source Serif 4 | YFBook SS4 |

Sources: https://github.com/google/fonts (ofl/*). License: SIL Open Font License 1.1 (see OFL.txt;
each font keeps its own copyright notice in its `name` table).
